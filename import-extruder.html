Perilaku import (tidak ada data yang dihapus): Achievement, Quality, dan Downtime semuanya disimpan dengan upsert berdasarkan kunci uniknya masing-masing — Achievement & Quality per (tanggal, shift), Downtime per (tanggal, mesin, shift, jam mulai, jam selesai, deskripsi). Kalau kombinasi itu sudah ada, datanya di-update; kalau belum ada, jadi baris baru. Upload ulang file yang sama atau file revisi jadi aman — tidak akan pernah dobel, dan baris lama di luar file tidak akan terhapus.

Catatan setup (sekali saja): tabel extruder_downtime perlu kolom row_key dengan unique constraint sebelum import ini bisa dipakai. Lihat komentar di bagian bawah script untuk perintah SQL-nya.
